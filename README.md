# HarperTubeData

Video lists for the YouTube channels in `channels.json`, published at <https://marler8997.github.io/HarperTubeData/> for [HarperTube](https://github.com/marler8997/HarperTube) to read.

The data is generated by `build_data.py`; it's never committed to `master`. The top of `build_data.py` documents the file layout and the API costs.

The `data` branch is a history of the published data, one commit per change. It shares no history with `master` and holds only the published files, so data updates never clutter the development history. `git clone --single-branch` skips it.

## How updates work

`.github/workflows/update.yml` runs every hour, on every push, and on demand:

1. Downloads the currently published data from GitHub Pages.
2. Runs `build_data.py`, which only asks YouTube about uploads not already in that data.
   - It checks each channel's free RSS feed first. A channel with no new uploads costs no API quota.
   - A new channel gets its whole upload history backfilled.
3. Deploys the result to GitHub Pages and commits it to the `data` branch. A scheduled run skips both when nothing changed.

## Setup

1. **Create a YouTube Data API key** (free).
   1. Go to <https://console.cloud.google.com/>, create a project, and enable **YouTube Data API v3**.
   2. Under *APIs & Services → Credentials*, choose *Create credentials → API key*.
   3. Under *API restrictions*, restrict the key to YouTube Data API v3.
2. **Add the key to GitHub.** Go to *Settings → Secrets and variables → Actions → New repository secret*. Name it `YOUTUBE_API_KEY` and paste the key.
3. **Turn on Pages.** In *Settings → Pages*, set *Source* to **GitHub Actions**.
4. **Run the first build by hand.** Go to *Actions → Update video data → Run workflow*, check **fresh**, and run it. There's nothing published to build on yet, so this run backfills every channel. Later runs are automatic.

## Adding a channel

Add it to `channels.json` and push. Find a channel's handle in its URL: `youtube.com/@SesameStreet` → `@SesameStreet`. The next run backfills just that channel. Removing a channel from `channels.json` drops its data.

## Running locally

Build from the published data (cheap):

```sh
YOUTUBE_API_KEY=... python build_data.py _site --previous https://marler8997.github.io/HarperTubeData/
```

Or build from scratch, which backfills every channel:

```sh
YOUTUBE_API_KEY=... python build_data.py _site --fresh
```

In PowerShell, set the key with `$env:YOUTUBE_API_KEY="..."` first. The output directory must be empty or not exist.
